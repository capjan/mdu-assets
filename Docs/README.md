# MDU Asset Server

The MDU Asset Server stores images for MDU documentation and hands out links that never change. Authors drop or paste an image and paste the ready-made Markdown into their pages.

> [!NOTE]
> The project is in planning. These pages describe the intended system and are updated together with the code.
